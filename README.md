# Pre-Entrega Automation Testing - Daiana Ramirez

### Propósito del proyecto
Automatización de flujos básicos en [saucedemo.com](https://www.saucedemo.com/) utilizando Selenium WebDriver y Python.

### Tecnologías utilizadas
- Python 3.14
- Selenium WebDriver
- Pytest

### Instrucciones de instalación
1. Clonar el repositorio.
2. Instalar dependencias: 
   `pip install -r requirements.txt`

### Ejecución de pruebas
Para ejecutar las pruebas y generar el reporte HTML, utiliza el siguiente comando:
`py -m pytest test/test_saucedemo.py -v --html=reports/reporte.html`
